# AgentShield AI — Project Requirements Baseline

> **Official title:** AgentShield AI: A Policy-Governed Framework for Secure and Autonomous AI Agent Execution
> **Tagline:** Autonomous Intelligence. Governed Execution. Trusted Outcomes.
> **Category:** AI Agents · Multi-Agent Systems · AI Security · Governance · Workflow Automation

## Core Principle

> AI agents can decide how to accomplish a task, but they cannot decide whether they are authorized to perform a sensitive action. That authority belongs to the independent governance engine.

## Stack
- Frontend: React, Vite, JavaScript, Tailwind CSS, shadcn/ui, Axios, Recharts
- Backend: Python, FastAPI, Pydantic, PyMongo, JWT, WebSockets
- Agents: LangGraph, LangChain, Gemini API
- Database: MongoDB Atlas + PyMongo
- Testing: Pytest, FastAPI TestClient

## Demonstration Workflow
Simulated expense claim automation using synthetic data. No real financial transfers.

## Five Objectives
1. Autonomous multi-agent execution (LangGraph)
2. Independent policy enforcement (deterministic governance engine)
3. Risk assessment and human approval
4. Monitoring and evaluation dashboard
5. Security, reliability and fault tolerance

## Success Criteria
- User submits natural-language task → agents coordinate → governance decides → approval if needed → execute → audit
- 50 benchmark test cases with measured metrics
- Working 3-minute demo
